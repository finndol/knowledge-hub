## Why this site exists

I'm learning Cloudflare by building a real project. This site grows from a static homepage into a full edge application over the course of ten stages. Each stage adds a new piece of the Cloudflare platform: dynamic rendering, KV storage, D1 databases, image optimization, AI-powered search, and more.

## What I'm hoping to learn

The big idea is edge-first development. Traditional web apps run on a server somewhere — usually one machine in one region. Edge platforms like Cloudflare flip this: your code runs in hundreds of data centers worldwide, close to whoever's asking for it. That changes how you architect everything.

By the end of this project I want to understand how static and dynamic rendering blend at the edge, when to reach for KV vs. D1 vs. R2, how to think about latency and caching, and how modern frameworks like Astro make all of this approachable.
